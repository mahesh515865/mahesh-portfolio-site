# Certificate image slots

Place each certificate photo in this folder using the exact filename below. The corresponding certificate detail page will display it automatically.

- `himshikhar-agentic-ai.jpg`
- `servicenow-cad.jpg`
- `servicenow-csa.jpg`
- `hp-life-data-science-analytics.jpg`

JPEG, PNG, and WebP image data are supported. If you use a different extension, update the matching `image` path in `src/data.js`.
